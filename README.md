# MOMO Home

Three.js로 만든 로봇의 인터랙티브 3D 집. 외부 AI 서비스 연결이나 배포 없이 로컬에서 실행합니다.

## 실행

이 폴더에서 `node serve.cjs`를 실행하고 http://127.0.0.1:4173 에 접속합니다.
Three.js와 필요한 모듈은 `vendor`에 포함되어 별도 설치가 필요 없습니다.

## 조작

- 바닥 클릭·터치: 가구와 벽을 피해 목적지로 걷기
- 방 이름: 침실·주방·화장실·거실·정원으로 이동
- 행동 버튼 또는 바닥의 금색 원: 해당 위치로 이동 후 행동
- WASD·방향키: 현재 카메라를 기준으로 직접 이동
- E: 가장 가까운 행동 / Esc: 행동 취소
- 드래그: 회전 / 휠·핀치·＋·−: 확대·축소
- 모모 따라가기: 로봇을 따라가는 카메라 / 집 전체 보기: 시점 복원
- Ⅱ: 일시 정지. 새 이동·행동을 선택하면 다시 재생됩니다.

침실에서는 잠자기, 주방에서는 요리와 식사, 화장실에서는 손 씻기·샤워·화장실 사용, 거실에서는 독서·춤, 정원에서는 물 주기가 가능합니다. 에너지·포만감·청결은 행동 결과에 따라 달라지며 새로고침하면 초기화됩니다.

## 검증

`node navigation.test.mjs`: 출입구 경로, 벽·가구 충돌, 집 경계, 막힌 경로를 확인합니다.

## 가구별 생활 행동

38가지 선택지를 제공합니다. 방을 선택하고 `행동 메뉴`를 열거나, 3D 가구를 직접 클릭해 해당 가구의 행동만 볼 수 있습니다. 행동 선택 후 메뉴가 접히며, 화면 아래 `행동 중지` 또는 Esc로 중단할 수 있습니다.

- 주방: 냉장고 열기·닫기, 채소 꺼내기·손질, 수프·채소볶음·샐러드 만들기, 식사, 물 마시기, 설거지
- 침실: 수면, 이불 정리, 침대 조명, 옷장 열기·닫기, 옷장 색상 변경, 커튼
- 화장실: 용변→물 내리기→뚜껑 닫기→손 씻기, 별도 물 내리기·뚜껑 조작, 양치, 샤워, 수건, 거울, 수도꼭지
- 거실: TV를 마주 보는 소파에서 TV 시청·휴식·독서, TV 전원과 3개 채널, 춤
- 정원: 식탁에서 식사·차 마시기, 물 주기, 꽃 돌보기·향기 맡기

요리는 냉장고에서 재료를 꺼내고, 문을 닫고, 손질하고, 조리하고, 그릇에 담는 6단계입니다. 완성 전에는 식사를 할 수 없고, 식사하면 음식이 소비되고 설거지가 남습니다. 가구의 열림/닫힘, TV 전원, 조명, 음식 상태는 페이지를 새로고침할 때까지 유지됩니다.

`npm test`는 경로 탐색과 생활 상태(요리 중단, 재료 조건, 음식 소비, TV 방향, 화장실 연속 동작)를 함께 확인합니다.

## 가까운 가구 조작 (최신)

- 가구를 누르면 모모가 앞으로 걸어갑니다. 가까워지면 가구 옆에 작은 조작 창이 나타납니다.
- **Space / E** 또는 조작 창의 큰 버튼: 냉장고·옷장·변기 뚜껑 열기/닫기, TV·조명·수도 켜기/끄기. 침대·소파·샤워기에서는 사용/중지를 전환합니다.
- **냉장고를 열면** 바로 옆에 채소·버터·생선·달걀·우유 선택지가 표시됩니다. 연달아 고른 재료는 순서대로 꺼내며 보유 수량에 반영됩니다.
- **가스레인지 옆 선택지**: 채소로 수프·채소볶음·샐러드, 생선+버터로 생선구이, 달걀+우유로 오믈렛. 필요한 재료가 없으면 먼저 냉장고에서 고르도록 안내합니다. 조리 완료 시 재료가 소비됩니다.
- 물체에서 멀어지면 조작 창이 사라집니다. Esc는 현재 행동을 멈추고 선택지를 접습니다.
- 하단의 `전체 행동`은 보조 메뉴로 유지됩니다. 조작 창은 모바일에서도 터치할 수 있습니다.

기존의 자동 재료 수집 6단계 대신, 냉장고에서 직접 재료를 고르는 흐름으로 바뀌었습니다. 전체 행동은 44가지입니다.

## 선택창·재료 꺼내기 수정

가구 옆 선택창을 146px 너비의 작은 버튼 묶음으로 줄이고 Space 안내와 선택지 접기 버튼을 제거했습니다. 냉장고 앞에서 재료를 누르면 경로를 다시 계산하지 않고 수량을 즉시 반영합니다. 집는 동작을 다른 재료 선택으로 중단하더라도 이미 고른 재료는 유지되며, 동작이 끝나도 중복 지급되지 않습니다. 문 여닫기와 Space 조작은 그대로 사용할 수 있습니다.
